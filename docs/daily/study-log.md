# 자동매매 시스템 학습 일지

## 2026-07-06
### 진행 작업
- **로컬 개발용 데이터베이스 환경 구축**
  - Windows PC에 Docker Desktop 설치 완료
  - `docker-compose.yml` 설정을 이용해 가볍고 격리된 MySQL 8.4 컨테이너 구동 성공
  - 로컬 3306 포트를 사용하도록 환경 연동
- **Prisma DB 마이그레이션 연동**
  - `npx prisma db push`를 사용하여 기존에 정의된 스키마 모델을 MySQL 데이터베이스에 테이블로 자동 생성
  - `npx prisma studio`를 구동하여 데이터베이스 테이블 구조 시각화 및 정상 생성 확인

### 배운 점 & 느낀 점
- 로컬 PC에 MySQL을 직접 수동 설치하지 않고 Docker 컨테이너를 활용함으로써 개발 환경의 격리성과 이식성을 높임.
- 환경 변수(`.env`)와 공유용 파일(`docker-compose.yml`)의 역할 차이를 이해함. 로컬 환경에 맞춰 `.env` 파일을 다르게 가져갈 수 있음을 파악함.
